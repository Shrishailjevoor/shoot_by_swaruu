# 🎬 Shoot by Swaruu — Cinematic Reel Studio

**Turning Moments Into Cinematic Stories.**

A modern, responsive website for **Shoot by Swaruu**, a cinematic reel production studio focused on creating high-quality reels, creative videos, and engaging visual content.

Designed with a bold black-and-deep-red aesthetic, cinematic animations, and a streamlined booking experience, the website provides visitors with a professional way to explore services and request a shoot.

---

## ✨ Overview

Shoot by Swaruu is a static front-end web project built with HTML, CSS, and JavaScript. It combines cinematic visual design with responsive layouts and interactive booking functionality.

The project is structured to make future customization, maintenance, and feature development easier.

### Key Highlights

- 🎥 Cinematic, dark-themed visual identity
- 📱 Responsive layout for desktop, tablet, and mobile
- 🎨 Black-and-red branding with dramatic visual accents
- 🖼️ Portfolio grid for showcasing creative work
- 💼 Service packages and optional add-on services
- 📅 Interactive shoot-booking interface
- 📍 Support for sharing shoot-location information
- 💬 WhatsApp booking integration
- ✨ Scroll animations and interactive visual effects
- 🧩 Modular HTML, CSS, and JavaScript structure

---

## 🚀 Features

### 1. Cinematic User Interface
A premium-inspired interface featuring dark backgrounds, red highlights, bold typography, and visual elements designed to reflect a professional video-production brand.

### 2. Responsive Design
The layout is designed to adapt to different screen sizes, providing a consistent browsing experience across desktops, tablets, and mobile devices.

### 3. Portfolio Showcase
A dedicated portfolio section for presenting cinematic reels and creative projects.

### 4. Service Packages
A structured presentation of available reel-production packages, helping potential clients understand the services offered.

### 5. Booking Interface
An interactive booking form designed to collect relevant shoot details, including client information, preferred date, shoot type, location, and optional requirements.

### 6. WhatsApp Integration
Booking details can be prepared for sharing through WhatsApp, making it easier for clients to contact the studio.

### 7. Location Information
The booking interface supports location details, with optional Google Maps link functionality where implemented.

### 8. Interactive Animations
JavaScript-powered visual enhancements, including scroll reveals, hover effects, and hero-section interactions.

### 9. Maintainable Code Structure
Separate files for styling, core interactions, and animations help simplify development and future updates.

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need:

- A computer with Windows, macOS, or Linux
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) (recommended)
- A modern web browser

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Shrishailjevoor/shoot_by_swaruu.git
```

### Step 2: Open the Project

```bash
cd shoot_by_swaruu
```

If you use Visual Studio Code, run:

```bash
code .
```

### Step 3: Run the Website

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a convenient local development workflow.

No build process is required if the project uses only static HTML, CSS, and JavaScript.

## 🌐 Deployment

The website can be hosted using a static-site hosting platform such as Netlify.

### Deployment Workflow

1. Push the latest project changes to GitHub.
2. Sign in to Netlify.
3. Import the GitHub repository.
4. Select the `main` branch.
5. Configure the publishing directory as `.` if the site is published directly from the repository root.
6. Deploy the website.
7. Open the generated public URL and test the website on desktop and mobile.

Future commits pushed to the connected branch can trigger automatic deployments when continuous deployment is configured.

## 🔐 Configuration and Integrations

Some integrations may require additional configuration.

- **WhatsApp:** Verify the destination phone number and message-generation logic in the JavaScript.
- **Google Maps:** Validate and test any submitted location links if this functionality is enabled.
- **Google Sheets:** If booking synchronization is implemented, configure the required endpoint and access permissions before deployment.
- **External assets:** Check that image, font, and script paths work correctly after deployment.

**Important:** Never commit API keys, private credentials, access tokens, or other secrets to a public repository. Use appropriate server-side handling for sensitive integrations.
