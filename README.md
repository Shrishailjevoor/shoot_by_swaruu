# Shoot by Swaruu — Cinematic Reel Studio

A responsive, static front-end for **Shoot by Swaruu**, styled to follow cinematic branding: black and deep-red studio design, lens-inspired logo, dramatic hero, portfolio grid, red-accented packages, add-on services, and clear travel/booking policies.
